## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Matiwane123/UNAMAT25572_Group-A-PT02508_Unathi_Matiwane_CDV05.git
   cd UNAMAT25572_Group-A-PT02508_Unathi_Matiwane_CDV05
   ```

2. Open `index.html` in your browser or use a local server:

   ```bash
   # Using Python 3
   python -m http.server 8000

   # Using Node.js (if http-server is installed)
   http-server
   ```

3. Navigate to `http://localhost:8000` in your browser.
